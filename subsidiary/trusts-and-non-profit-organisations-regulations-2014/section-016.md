16. A person commits an offence and is liable, on summary
conviction, to a fine not exceeding fifty thousand dollars if the
person, with intent to deceive or for any purpose of these
Regulations -
(a) provides any information, makes any
representation or submits any document or return
that he knows to be false or materially misleading
or does not believe to be true; or
(b) recklessly provides any information, makes any
representation or submits any document or return
that is false or materially misleading.
