attributes and link the database to the chart based
on the aerodrome data which satisfy the require-
ments of the Civil Aviation (Aeronautical Infor-
mation Services) Regulations, 2024;
(b) portray the following aerodrome features by an
appropriate symbol—
(i) aerodrome reference point;
(ii) runways, with designation numbers, and if
available, stopways and clearways; and
(iii) taxiways, aprons, large building sand
other prominent aerodrome features;
(c) link the portrayed aerodrome feature to the fol-
lowing associated attributes in the database –
